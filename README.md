# Aniyomi+

**Building Aniyomi+ — an enhanced manga & anime experience with Mihon-compatible extensions.**

Aniyomi+ is an enhanced Android manga and anime app built on the Aniyomi ecosystem, with additional features and a refined interface.

## ✨ Features

- Manga and anime library
- Refined dark interface
- Mihon-compatible extensions
- Additional enhancements and customization
- Android app
